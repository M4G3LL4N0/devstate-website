Developer storage · compression and recovery

Shrink any project to its essential state. Restore it when you come back.

Startup folders fill up with node_modules, .next, caches, logs, and local experiments until the disk calls it System Data. DevState is a local CLI that separates source from rebuildable junk, archives what GitHub does not hold, and writes memory files so a later agent can rebuild the project.
